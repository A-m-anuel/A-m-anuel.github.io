~/about

I have worked in security since 2015: first on national-scale government systems at Ethiopia's Information Network Security Agency, then in health and fintech, and now in cloud and product security in Germany. I have done hands-on penetration testing, mobile and API assessments, manual code review, and built SAST, DAST and SCA pipelines.

What I enjoy most is working next to engineers. I would rather build secure defaults and paved roads than file another ticket, and I like turning security knowledge into tools other people can run, such as mcp-guard.

Outside my day job I have taught software testing to members of the Ethiopian community in the US to help them move into tech careers. Around 50 of the 87 people I certified found technical jobs.

~/projects

Open-source tools I build to make security checks repeatable.

mcp-guard

Security scanner for MCP (Model Context Protocol) and AI agent configurations.

AI assistants such as Claude, Cursor and VS Code now launch third-party MCP servers with the user's privileges. mcp-guard reads their config files and flags the risky ones before an agent ever starts them.

  • Hardcoded secrets, unpinned and typosquatted packages
  • Over-broad filesystem access, container escapes, auto-approved tools
  • Tool poisoning, hidden Unicode instructions and rug pulls
  • SARIF output and a GitHub Action for code scanning
